# 🎓 수강신청 연습 시스템
실제 대학 수강신청 시스템의 화면과 주요 흐름을 참고하여 구현한 **수강신청 연습용 웹 애플리케이션**입니다. 학생들이 수강신청 과정을 미리 경험하고, 강좌 조회부터 예비수강 및 수강신청까지의 흐름을 익힐 수 있도록 개발했습니다.

## 📌 프로젝트 소개
수강신청은 제한된 시간 안에 강좌를 조회하고 원하는 과목을 신청해야 하는 과정입니다. 하지만 수강신청을 연습할 기회가 없어, 실제 수강신청에서 실수하는 경우가 많았습니다. 이를 다른 학우들도 불편하다 느낄것으로 판단하여
실제 수강신청 전에 인터페이스와 신청 절차를 익힐 수 있도록 웹 기반 연습 시스템을 구현했습니다.
단순한 화면 구현에 그치지 않고, 로그인부터 수강신청 페이지 진입, 강좌 조회 및 신청 내역 확인으로 이어지는 사용자 흐름을 구성했습니다.

## ✨ 주요 기능


- **로그인:** 사용자 입력값을 확인하고 기본 페이지로 이동하는 로그인 흐름 구현
- **강좌 조회:** 개설 강좌의 과목명, 학점, 이수 구분, 강의 시간 등 정보 확인
- **예비수강:** 관심 강좌를 미리 확인하고 예비수강 내역을 관리하는 화면 구성
- **빠른 수강신청:** 수강번호를 이용한 과목 신청 인터페이스 구현
- **수강 내역 확인:** 신청한 과목과 총 신청 학점 등을 확인할 수 있는 화면 구성



## 🛠️ 기술 스택



- **Backend:** Python, Flask

- **Frontend:** HTML 템플릿 기반 웹 페이지

- **Deployment:** Docker, Oracle cloud, Duckdns, NPM manager



## 🏗️ 프로젝트 구조



```text

sugang_practice_new/

│   ├── basic.html       # 기본 페이지
```

## 🚀 실행 방법



### 1. 저장소 클론



```bash

git clone https://github.com/rlaxodud6842/sugang_practice_new.git

cd sugang_practice_new

```



### 2. Flask 설치



```bash

pip install flask

```



### 3. 서버 실행



```bash

python main.py

```



브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.
